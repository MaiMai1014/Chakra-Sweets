CHAKRA SWEETS WEBSITE — UPDATED MENU VERSION

This version has exactly 15 menu cards. The nine Tailed Beast pie flavours are grouped together into one card with a single collage image and an individual name and description for every pie.

PREVIEW
1. Extract this ZIP.
2. Open the chakra_sweets_website folder.
3. Double-click index.html.

EDITING
- Edit index.html for names, descriptions, prices, and page text.
- Edit style.css for colours and layout.
- Product photos are in the images folder.

PUBLISHING
Upload all extracted files and the images folder to a static host such as Cloudflare Pages. Keep the images folder alongside index.html and style.css.
