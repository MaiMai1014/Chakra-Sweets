CHAKRA SWEETS WEBSITE

Files:
- index.html: website pages and menu content
- style.css: layout and styling
- images/: logo, favicon source, hero artwork, and menu pictures

Preview:
Open index.html in a browser.

Publish with GitHub + Cloudflare Pages:
1. Upload the CONTENTS of this folder to a GitHub repository (keep index.html at the root).
2. In Cloudflare Pages, connect the repository.
3. Framework preset: None
4. Build command: exit 0
5. Build output directory: .
6. Deploy.
