CHAKRA SWEETS WEBSITE

Files:
- index.html: Introduction / welcome page
- menu.html: 15 menu cards
- contact.html: contact information
- styles.css: responsive red, white, orange and black styling
- favicon.png: browser-tab icon
- assets/: logo, Naruto artwork and the 15 dessert images

To use:
1. Keep the folder structure intact.
2. Open index.html in a browser to preview.
3. For publishing, upload the contents of this folder to your web host (for example GitHub Pages or Cloudflare Pages).
4. Use the dropdown at the top to move between Introduction, Menu and Contact.

Note: Menu photo assignments are matched to the closest-looking images from the supplied 15-image ZIP. All original image files are included in assets/.
